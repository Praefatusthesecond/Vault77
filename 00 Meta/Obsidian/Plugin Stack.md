> _Plugins are part of the system, not decorations._

## Core Plugins (Always Enabled)

### Dataview

**Why**

- Turns notes into queries
    
- Eliminates manual lists
    

**Used for**

- Project dashboards
    
- Task overviews
    
- Knowledge indexes
    

---

### Templater

**Why**

- Reduces friction
    
- Enforces consistency
    

**Used for**

- New notes
    
- Projects
    
- Daily notes
    

---

### Calendar

**Why**

- Visual access to time
    
- Navigation through days
    

Used primarily with Daily Notes.

---

### Git

**Why**

- Version control
    
- Backups
    
- Peace of mind
    

Rules:

- Commit regularly
    
- Never rely on memory alone
    

---

### Tasks

**Why**

- Actions live where context lives
    

Rules:

- Tasks belong to notes, not a separate app
    
- Queries replace task lists
    

---

### Advanced Tables

**Why**

- Structured thinking in Markdown
    
- Comparisons without spreadsheets
    

---

## Plugin Rule

No plugin is added without:

1. A clear purpose
    
2. A documented use case
    
3. A place in this file
