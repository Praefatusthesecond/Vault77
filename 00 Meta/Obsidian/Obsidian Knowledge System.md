> _The operating system of this vault._

## Purpose

This document defines **how and why** this Obsidian vault is used.  
When unsure where something belongs, how to write a note, or whether something should exist at all — start here.

This document is **authoritative**.

---

## Core Principles

### 1. Notes are thinking tools

- Notes are not documents, archives, or blogs
    
- Notes exist to **clarify thinking**
    
- Imperfect notes are acceptable; unused notes are not
    

---

### 2. Atomic by default

- One note = one idea
    
- Notes must make sense when opened directly
    
- If a note feels like a chapter, split it
    

---

### 3. Links over hierarchy

- Folders are logistical, not semantic
    
- Meaning comes from links and context
    
- If something belongs in multiple places → link it
    

---

### 4. Capture first, organize later

- Inbox is allowed to be messy
    
- Organization happens during review, not capture
    
- Speed beats structure in the moment
    

---

## Golden Rules

- Every note should eventually link to _something_
    
- If you write the same thing twice, create a note for it
    
- If a process repeats, document it
    
- If future-me would ask “why?”, explain it now
    

---

## When Lost

Ask these questions **in order**:

1. Is this actionable? → Project / Task
    
2. Is this an idea worth keeping? → Knowledge
    
3. Is this ongoing responsibility? → Area
    
4. Is this raw / unclear? → Inbox
    

If still unclear → Inbox, review later.
