# Zabbix Templates

Templates define *what* is monitored.

## What templates include
- Items
- Triggers
- Graphs
- Discovery rules
- Macros

## Template strategy
- Prefer vendor-maintained templates
- Clone before customization
- Keep environment-specific logic out of templates

## Examples
- OS Linux
- OS Windows
- Zabbix Server
- Database templates
