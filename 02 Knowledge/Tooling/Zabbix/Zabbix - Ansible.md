# Ansible

Ansible is an agentless automation tool used for configuration management, provisioning, and orchestration.

## Core concepts
- Playbooks
- Roles
- Inventory
- Variables

## Common use cases
- Server provisioning
- Application deployment
- Monitoring agent installation

## Ansible & Zabbix
- Install agents
- Register hosts
- Assign templates
- Enforce configuration consistency
