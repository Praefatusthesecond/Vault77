# Discovery

Discovery allows Zabbix to auto-detect:
- Hosts
- Interfaces
- Filesystems
- Services

## Types
- Network discovery
- Low-level discovery (LLD)

## Use cases
- Auto-register servers
- Dynamic disks
- Containers
