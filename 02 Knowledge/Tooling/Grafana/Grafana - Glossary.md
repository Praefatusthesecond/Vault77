# Glossary

- **Panel**: a visualization backed by one or more queries.
- **Dashboard**: collection of panels + layout + variables.
- **Data source**: backend queried by Grafana (Prometheus/Loki/etc.).
- **Variable**: templating mechanism for dynamic dashboards.
- **Alert rule**: condition evaluated over time that triggers notifications.
- **Contact point**: destination for notifications.
- **Notification policy**: routing logic for alerts.
