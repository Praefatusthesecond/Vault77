## 4) Git in VS Code (daily driver basics)

**You want these habits:**

- Stage hunks, not files (when possible)
    
- Always review diff before commit
    
- Use “discard” carefully (it’s “delete,” not “undo”)
    

**Key tools**

- Source Control panel: `Ctrl+Shift+G`
    
- Timeline / file history
    
- Blame (usually via GitLens, optional but very useful)
    

**Pro tip**

- Use the built- in diff viewer for confidence, but do merges/rebases intentionally.
