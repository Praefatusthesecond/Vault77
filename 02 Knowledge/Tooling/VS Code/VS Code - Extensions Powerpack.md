## Extensions Powerpack (your baseline kit)

A practical default set for your world (DevOps + Markdown + PowerShell):

- YAML + schema support
    
- PowerShell
    
- Terraform
    
- GitLens (optional but strong)
    
- EditorConfig
    
- Markdown tools (preview, lint)
    
- Remote Development (SSH/WSL/Containers depending on your setup)
    

Rule of thumb: **extensions should earn their keep**. If it slows startup and you don’t use it weekly, yeet it.
