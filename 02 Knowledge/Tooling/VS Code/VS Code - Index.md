# VS Code

## What VS Code is for (in our workflow)
- Editing code + infra (Terraform, YAML, PowerShell, Markdown)
- Bulk refactors (safe find/replace, multi- cursor, structural edits)
- Git ops without leaving editor (review, stage, blame, history)
- Debugging (apps + scripts) and repeatable tasks
- Remote work (SSH/WSL/containers) without context switching
