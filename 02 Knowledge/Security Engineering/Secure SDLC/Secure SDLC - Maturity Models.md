# Secure SDLC Maturity Models

## OWASP SAMM

Framework to measure and improve software security posture.

---

## NIST SSDF

Secure Software Development Framework.

Focus:
- Secure design
- Secure coding
- Secure testing
- Continuous improvement

---

## SLSA

Supply-chain Levels for Software Artifacts.

Defines increasing levels of build integrity.

---

## Why Use Maturity Models?

- Benchmark security posture
- Guide improvement roadmap
- Support compliance audits
- Align security with business goals
