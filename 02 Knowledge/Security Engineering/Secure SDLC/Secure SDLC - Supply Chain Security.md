# Supply Chain Security

Modern attacks target build systems and dependencies.

---

## Risks

- Dependency confusion
- Typosquatting packages
- Compromised open-source libraries
- Malicious CI plugins
- Compromised artifact registry

---

## Mitigations

- Lock dependency versions
- Verify checksums
- Use private registries
- Enforce artifact signing
- Restrict pipeline permissions

---

## Key Frameworks

- SLSA
- NIST SSDF
- SBOM enforcement
