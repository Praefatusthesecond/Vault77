# SBOM (Software Bill of Materials)

An SBOM lists all components within software.

Includes:
- Dependencies
- Versions
- Licenses

---

## Why It Matters

- Vulnerability tracking
- Compliance
- Rapid response to CVEs

---

## Artifact Integrity

- Sign artifacts
- Verify signatures before deployment
- Use immutable registries
- Prevent overwrite attacks
