# Secure SDLC – Overview

## What Is Secure SDLC?

Secure Software Development Lifecycle (Secure SDLC) integrates security practices into every phase of development.

Security is not a final test phase.
It is embedded from design to deployment.

---

## Traditional vs Secure SDLC

Traditional SDLC:
- Requirements
- Design
- Development
- Testing
- Deployment

Secure SDLC:
- Security requirements
- Threat modeling
- Secure design
- Secure coding
- Automated security testing
- Security validation
- Continuous monitoring

---

## Core Principles

- Shift security left
- Automate security checks
- Reduce manual review dependency
- Treat infrastructure as code securely
- Monitor continuously
- Improve iteratively
