# Logging Fundamentals

## Why Logging Matters

Logs provide:
- Accountability
- Incident reconstruction
- Compliance evidence
- Behavioral insight

---

## Types of Logs

### Authentication Logs
Login attempts, MFA failures, token issuance.

### Authorization Logs
Role assignments, policy changes.

### Application Logs
Errors, suspicious behavior.

### Infrastructure Logs
VM events, container events.

### Network Logs
Firewall logs, DNS logs.

---

## Logging Principles

- Log security-relevant events
- Avoid logging sensitive secrets
- Standardize formats
- Centralize logs
- Protect log integrity
