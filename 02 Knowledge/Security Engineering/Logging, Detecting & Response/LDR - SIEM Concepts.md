# SIEM (Security Information & Event Management)

A SIEM:

- Aggregates logs
- Correlates events
- Detects anomalies
- Generates alerts

---

## Core Functions

- Event correlation
- Threat detection
- Alert generation
- Dashboard visualization
- Incident timeline reconstruction

---

## Challenges

- Alert fatigue
- Poorly tuned rules
- Noise vs signal imbalance
