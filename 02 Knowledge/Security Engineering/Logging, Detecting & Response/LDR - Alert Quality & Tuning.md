# Alert Quality

A good alert must:

- Be actionable
- Have clear severity
- Include context
- Suggest next steps

---

## Alert Fatigue Causes

- Noisy rules
- Duplicate alerts
- Lack of prioritization

---

## Tuning Strategy

- Measure false positives
- Remove redundant rules
- Add contextual filters
