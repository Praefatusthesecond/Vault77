# Authentication Mechanisms

## Something You Know
- Password
- PIN

## Something You Have
- Hardware token
- Phone (MFA)

## Something You Are
- Biometrics

---

## Modern Mechanisms

- Multi-Factor Authentication (MFA)
- Passwordless (FIDO2)
- OAuth tokens
- Short-lived certificates
- OIDC federation

---

## Cloud Best Practice

- Enforce MFA for privileged accounts
- Avoid long-lived access keys
- Use short-lived tokens
- Prefer federated login
