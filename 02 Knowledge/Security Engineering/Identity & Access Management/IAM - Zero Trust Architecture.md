# Zero Trust Architecture

Principle:
Never trust, always verify.

---

## Key Pillars

- Strong identity
- Device compliance
- Continuous verification
- Least privilege
- Micro-segmentation

---

## IAM Role in Zero Trust

IAM enforces:
- Context-based access
- Risk-based authentication
- Just-in-time elevation
