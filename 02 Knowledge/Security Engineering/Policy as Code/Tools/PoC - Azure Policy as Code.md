# Azure Policy as Code

Azure Policy enables governance through declarative rules.

## Policy effects
- Deny
- Audit
- Append
- Modify
- DeployIfNotExists

## Policy as Code approach
- Define policies in JSON
- Store in Git
- Deploy via Terraform or Bicep

## Typical use cases
- Enforce tags
- Restrict regions
- Require encryption
- Control SKUs

## Why it works well
- Native platform support
- Strong reporting
- Built-in remediation

Azure Policy is enforcement-first governance.
