# Drift and Continuous Compliance

Drift happens when reality diverges from intent.

## Sources of drift
- Manual console changes
- Hotfixes
- Emergency access
- Legacy resources

## Detection methods
- Scheduled policy scans
- Inventory exports
- Cloud-native compliance tools

## Response models
- Alert only
- Ticket creation
- Auto-remediation

Policy as Code closes the loop between intent and reality.
