# Testing Policies

Untested policies are liabilities.

## What to test
- Allowed cases
- Denied cases
- Edge cases
- Exception handling

## Test styles
- Rego unit tests
- Golden input files
- CI regression tests

## Benefits
- Confidence to enforce
- Safer refactors
- Easier reviews

Treat policies like production code.
