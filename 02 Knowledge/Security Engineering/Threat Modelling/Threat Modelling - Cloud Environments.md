# Threat Modeling – Cloud Environments

Cloud threat modeling focuses on:

- IAM abuse
- Metadata service exploitation
- Over-permissive roles
- Public storage misconfiguration
- Cross-account trust misuse

---

## Common Attack Patterns

- Privilege escalation via misconfigured IAM
- Token reuse
- Service principal abuse
- Storage enumeration
- Control plane takeover

---

## Defensive Controls

- Least privilege IAM
- Role separation
- Conditional access
- Network segmentation
- Logging & detection mapping
