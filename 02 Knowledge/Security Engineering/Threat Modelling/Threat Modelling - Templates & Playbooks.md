# Threat Modeling – Template

## 1. Scope
Define system boundaries.

## 2. Architecture Diagram
Attach DFD.

## 3. Assets
List sensitive components.

## 4. Trust Boundaries
Identify privilege changes.

## 5. STRIDE Analysis
Per component.

## 6. Risk Scoring
Apply DREAD.

## 7. Mitigations
Define security controls.

## 8. Residual Risk
Accept / Transfer / Mitigate.

## 9. Logging & Detection
Map to monitoring strategy.

---

# Playbook – Quick Threat Modeling Session (60 min)

1. Draw DFD (15 min)
2. Identify assets (10 min)
3. Apply STRIDE (20 min)
4. Score risks (10 min)
5. Assign mitigations (5 min)
