# ISO/IEC 27001 – Overview

ISO/IEC 27001 is an international standard that defines the requirements for an Information Security Management System (ISMS).

Its goal is to help organizations:
- Protect confidentiality, integrity and availability of information
- Manage information security risks systematically
- Demonstrate security governance to stakeholders

ISO 27001 is **risk-based**, not checklist-based.

## What ISO 27001 Is
- A **management system standard**
- Technology-agnostic
- Applicable to organizations of any size

## What ISO 27001 Is Not
- Not a technical hardening guide
- Not a fixed list of mandatory controls
- Not a one-time project

## Key Principle
> Security controls exist to treat *identified risks*, not to satisfy auditors.
