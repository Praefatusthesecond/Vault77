# ISO/IEC 27001 – Structure of the Standard

ISO/IEC 27001 consists of:
- **Clauses 4–10** (mandatory requirements)
- **Annex A** (reference control set)

## Clauses Overview

| Clause | Topic |
|------|------|
| 4 | Context of the organization |
| 5 | Leadership |
| 6 | Planning |
| 7 | Support |
| 8 | Operation |
| 9 | Performance evaluation |
| 10 | Improvement |

Clauses 4–10 define **what must exist** in the ISMS.

## Annex A
Annex A provides:
- A catalogue of information security controls
- Used as a **reference**, not a checklist
