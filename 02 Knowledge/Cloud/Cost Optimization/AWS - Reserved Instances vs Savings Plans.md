# Reserved Instances vs Savings Plans

## Reserved Instances

- Instance-family specific
    
- Region-specific
    
- Highest discount (if used correctly)
    
- Less flexible
    

---

## Savings Plans

- More flexible
    
- Commit to hourly spend instead of instance type
    
- Applies across services
    

---

## When to Use Which?

Stable workload → RIs  
Mixed workload → Savings Plans  
Uncertain future → No upfront + monitoring first
