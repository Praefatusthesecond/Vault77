# Cloud - FinOps Fundamentals

## What is FinOps?

FinOps = Financial Operations for Cloud.

It aligns:

- Engineering
    
- Finance
    
- Leadership
    

---

## FinOps Principles

1. Teams own their cloud usage
    
2. Cost visibility must be real-time
    
3. Optimization is continuous
    
4. Business value > raw cost reduction
    
5. Automation over manual governance
    

---

## FinOps Lifecycle

1. Inform (visibility & reporting)
    
2. Optimize (rightsizing & architecture)
    
3. Operate (governance & automation)
    

---

## Key Metrics

- Cost per workload
    
- Cost per user
    
- Cost per environment
    
- Cost per transaction
    
- Forecast vs actual
    
- Idle resource ratio
