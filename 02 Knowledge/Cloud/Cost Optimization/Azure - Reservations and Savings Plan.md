# Azure Reservations vs Savings Plan

## Reservations

- Specific SKU
    
- Region-bound
    
- Maximum savings
    
- Requires stable workload
    

---

## Savings Plan

- Spend-based commitment
    
- Flexible across compute services
    

---

## Strategy

1. Monitor usage 30–90 days
    
2. Identify baseline usage
    
3. Reserve only baseline
    
4. Keep elasticity uncommitted
