# Cloud Cost Optimization Checklist

## Compute

- Remove idle VMs
    
- Downsize overprovisioned VMs
    
- Implement reservations
    
- Use spot where safe
    

---

## Storage

- Lifecycle policies active
    
- Remove unattached disks
    
- Tier cold data
    
- Delete old backups
    

---

## Networking

- Reduce data egress
    
- Optimize NAT usage
    
- Use private endpoints
    

---

## Governance

- Budget alerts configured
    
- Mandatory tagging enforced
    
- Idle resource review monthly
    
- FinOps review quarterly
