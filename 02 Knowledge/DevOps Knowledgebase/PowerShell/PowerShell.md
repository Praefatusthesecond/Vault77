# PowerShell

PowerShell is Microsoft’s object-oriented automation and configuration framework built on .NET.

It is a **core DevOps skill** for:
- Windows Server administration
- Active Directory automation
- CI/CD pipelines
- Infrastructure configuration
- Security auditing
- Hybrid cloud automation (Azure, AWS)
