# PowerShell - Fundamentals

PowerShell is:

- Object-oriented
- Pipeline-based
- Built on .NET
- Cross-platform (PowerShell Core / pwsh)

---

## Versions

- Windows PowerShell 5.1 (Legacy, Windows-only)
- PowerShell 7+ (Cross-platform, recommended)

Check version:

$PSVersionTable

---

## Command Structure

Verb-Noun naming convention:

Get-Service
Set-ExecutionPolicy
New-Item
Remove-User

List verbs:

Get-Verb
