# Bash - Core Commands

## Navigation
```bash
pwd
ls -la
cd /path
```

## File Operations
```bash
cp file1 file2
mv file1 file2
rm file
mkdir folder
```

## Search

```bash
grep "text" file
find /path -name "*.log"
```

## Disk Usage

```bash
df -h
du -sh *
```

## System Info

```bash
uname -a
top
htop
free -h
```

## Networking

```bash
curl https://example.com
wget https://example.com
netstat -tulnp
ss -tulnp
```
