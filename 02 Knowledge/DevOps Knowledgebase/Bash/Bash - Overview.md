# Bash - Overview

## What is Bash?

Bash (Bourne Again SHell) is the default shell on most Linux systems.  
It is both:

- An interactive command interpreter
- A scripting language

## Where is it used?

- Linux servers
- Docker containers
- CI/CD pipelines (GitLab, GitHub Actions, Azure DevOps)
- Kubernetes init containers
- Cloud VMs
- Embedded systems

## Compare to PowerShell

| Feature | Bash | PowerShell |
|----------|-------|------------|
| Data type | Text streams | Objects |
| Default OS | Linux | Windows |
| Philosophy | Small tools chained together | Structured automation |
| Config files | Plain text | Structured formats (JSON/XML/YAML) |

## Why Bash matters

If you work in:
- Ansible
- GitLab CI
- Docker
- Kubernetes
- Ubuntu servers

You are using Bash whether you realize it or not.
