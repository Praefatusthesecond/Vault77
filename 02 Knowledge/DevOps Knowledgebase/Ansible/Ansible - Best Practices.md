# Ansible - Best Practices

- Use roles
    
- Avoid hardcoded values
    
- Use group_vars and host_vars
    
- Keep playbooks small
    
- Use version control
    
- Use ansible-lint
    
- Encrypt secrets
    
- Test in staging first
    
- Keep idempotency sacred
